# Brand assets

The approved identity for **dienstleistungs.cloud** is **B2 — Balanced Cube**:
a geometric cube inside a hexagonal frame.

All logo and favicon files in this directory are copied unchanged from
`dienstleistungs-cloud-b2-final.zip`. No new logo has been designed.
The source archive's `favicon-final-test.png` is a test preview and is not
included among the production assets.

## Files

| Path | Purpose |
| --- | --- |
| `logos/logo.svg` | Transparent teal logo. |
| `logos/logo-white.svg` | Transparent white logo for dark backgrounds. |
| `favicons/favicon.svg` | Teal B2 mark on a fixed graphite tile; used in the organization profile. |
| `favicons/favicon-16.png`, `favicon-32.png`, `favicon-64.png` | Standard raster favicon sizes. |
| `favicons/favicon.ico` | ICO favicon. |
| `favicons/favicon-small.svg` | Simplified mark for small sizes. |
| `favicons/favicon-small-16.png`, `favicon-small-32.png` | Simplified raster favicon sizes. |

## Palette

| Color | Value |
| --- | --- |
| Teal | `#28C7BE` |
| Graphite | `#101C1B` |

These values come from the supplied SVG files. Do not introduce lime.

## Profile usage

The organization profile uses themed artwork in `../profile/`. The header
embeds the original `logos/logo.svg` geometry unchanged; the approved source
logos and favicons remain unchanged. See `../profile/README.md` for layout,
accessibility and update details.
